## 2. Planned Features

Features intended for implementation as part of the initial project scope.

### 2.1. General Features

General functionalities related to application navigation and user interaction.

- [ ] **Terminal-Based Menu:** Provide an interactive terminal menu that allows users to navigate through the application and access its available options.

### 2.2. Client-Side Features

Functionalities provided and managed on the client side.

- [ ] **User Registration:** Allow users to register with the server by providing their personal credentials, including a username and password.
- [ ] **User Authentication:** Allow registered users to log in to the server and establish an authenticated session for data exchange.
- [ ] **Connection Status Monitoring:** Allow users to check their connection status and verify their connectivity to the server.
- [ ] **Contact Management:** Allow users to add contacts and block other users.
- [ ] **Message Exchange:** Allow users to send and receive messages while connected to the server.
- [ ] **Local Data Persistence:** Store relevant user data locally, including received messages, outgoing messages pending delivery, and contact information.

### 2.3. Server-Side Features

Functionalities handled and managed by the server.

- [ ] **Client Registration Management:** Handle registration requests from new clients and process their registration information.
- [ ] **User Profile Management:** Store user profiles upon registration and assign each user a unique identifier.
- [ ] **Client Relationship Management:** Manage relationships between clients, including unknown contacts, established contacts, and blocked users.
- [ ] **Reliable Message Delivery:** Handle message transfers between clients and provide delivery confirmation to ensure that messages are successfully received.

### 2.4. Communication Features

Functionalities defining the communication mechanisms between clients and the server.

- [ ] **Request-Based Communication:** Implement a request-based communication mechanism in which clients exchange structured request objects with the server.
- [ ] **Request Processing:** Allow the server to identify, process, and respond to incoming client requests.
- [ ] **Response Handling:** Enable clients to receive and interpret server responses to their requests.
